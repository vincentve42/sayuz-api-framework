# Sayuz PHP API

### What is Sayuz PHP API?

Sayuz api is a base project that contain all the essential feature for api application written in php.



### Usage
1. Run Server
```php src/sayuz.php run```
2. Create New Controller
``` php sr/sayuz.php create:controller [name] ```
3. Create New Model
``` php sr/sayuz.php create:model [name] ```
